# Automação de Versionamento de Diretórios

Código em Python pra automatizar a criação e remoção de arquivos '.gitkeep' em um repositorio local. O código percorre os diretórios, garantindo que pastas vazias recebam o '.gitkeep' para serem versionados pelo Git, e remove esse arquivo de pastas que já tem algum conteúdo. Todo esse processo é salvo em um arquivo de log.

## Como rodar 

#### 1 - Tenha o python instalado no seu pc
#### 2 - Clone o repositório para o seu pc
#### 3 - Coloque o 'main.py' na raiz do repositório
#### 4 - Execute o arquivo 'main.py' e veja no terminal a quantidade de arquivos criados ou removidos
